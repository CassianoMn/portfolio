# Portfólio Pessoal — Cassiano Menezes

Portfólio profissional de Engenharia de Software desenvolvido com foco em performance, clareza técnica e arquitetura limpa. O projeto segue a estética **Clean Minimalist Editorial** com alto contraste, tipografia refinada e suporte bilíngue nativo (Português pt-BR e Inglês EN).

---

## ⚡ Tecnologias & Arquitetura

- **Front-End:** HTML5 Semântico, CSS3 Moderno (Custom Editorial Tokens + Tailwind CSS utility system) e JavaScript Vanilla (ES6+ modular).
- **Sem Dependências Pesadas:** Execução direta no navegador, sem necessidade de transpilação ou bundlers complexos.
- **Top Profile Switcher:** Filtragem dinâmica em tempo real para múltiplos perfis técnicos:
  - *Visão Geral* (Full Stack Engineer)
  - *.NET / C#* (Back-End, ASP.NET Core, EF Core, Arquitetura Hexagonal)
  - *React & TypeScript* (Front-End Moderno, Node.js, REST e GraphQL)
  - *AI Engineering & Automação* (Google Gemini, Agentes de IA, n8n, Webhooks)
- **Central de Currículos ATS:** Download direto de currículos adaptados e diagramados em padrão One-Page Standard para leitores ópticos.
- **Ações Rápidas de Contato:** Cópia de e-mail em 1 clique com notificação toast instantânea, WhatsApp e redes profissionais.
